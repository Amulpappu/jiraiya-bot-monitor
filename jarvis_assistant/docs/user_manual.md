# Jarvis Personal AI Assistant - User Manual & Command Reference

## Interface Overview
- **Sidebar**: Switch between Assistant Chat, Performance Dashboard, Memory, and Plugins. Toggle Dark/Light visual themes.
- **Chat View**: Conversational interface with markdown rendering, code blocks, microphone voice button, file attachment button, and message input.
- **Performance Dashboard**: Real-time CPU %, RAM GB, System Storage (C:), Battery Status, and active process count with quick optimization triggers.

---

## Supported Commands Reference

- `Open Chrome` / `Launch Steam` / `Open VS Code` / `Open Discord`
- `Close Chrome` / `Close Notepad`
- `Mute volume` / `Volume up` / `Volume down`
- `Lock PC`
- `Sleep laptop`
- `Shutdown after 30 minutes`
